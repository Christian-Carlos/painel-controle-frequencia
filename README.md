# Painel de Controle de Frequência

## Descrição
Sistema desenvolvido com Google Apps Script para controle de frequência de alunos, com painel administrativo, visualização de dados e integração com AppSheet.

---

## Funcionalidades
- Registro de presença, ausência e justificativa
- Visualização de dados em painel administrativo
- Filtros por turno e horário
- Consulta individual de alunos
- Histórico de frequência
- Integração com AppSheet

---

## Tecnologias
- Google Apps Script
- JavaScript
- HTML
- CSS
- Google Sheets
- AppSheet

---

## Estrutura do Projeto

### Backend — Code.gs
Responsável pela leitura da base de dados, processamento das informações de frequência, aplicação de filtros e retorno dos dados para o painel.

### Frontend — index.html
Interface administrativa com listagem de alunos, filtros, visualização de dados e interação com o backend.

---

## Arquivos
- `Code.gs` — Backend em Google Apps Script
- `index.html` — Interface do painel
- `README.md` — Documentação

---

## Diferenciais
- Integração com AppSheet
- Processamento rápido de dados
- Interface organizada e responsiva
- Controle de status dos alunos (ativo/inativo)
- Estrutura otimizada para uso contínuo
